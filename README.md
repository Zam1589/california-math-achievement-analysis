# Chronic Absenteeism and Mathematics Achievement in California Public Schools

## Research Question

To what extent is chronic absenteeism associated with mathematics achievement among California public schools?

## Motivation

Student attendance is an important component of educational participation and may be associated with academic outcomes. This project examines school-level patterns in chronic absenteeism and mathematics achievement across California public schools.

## Data

This project uses publicly available 2024–25 data from the California Department of Education.

Initial datasets:
- Mathematics Academic Indicator
- Chronic Absenteeism Indicator

Additional school demographic and enrollment data may be incorporated in later stages of the analysis.

## Methods

Planned analyses include:
- Data cleaning and merging
- Exploratory data analysis
- Data visualization
- Correlation analysis
- Simple linear regression
- Multiple linear regression
- Model diagnostics
